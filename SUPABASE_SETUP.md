# Підключення Supabase та адмін-панелі

Після налаштування відкрийте `https://ВАШ-САЙТ/admin.html`.

## 1. Створіть Supabase-проєкт

У Supabase створіть проєкт і відкрийте **Project Settings → API**. Скопіюйте Project URL і anon/publishable key у `assets/js/config.js` (`supabaseUrl`, `supabaseAnonKey`). У браузерний код не вставляйте `service_role` ключ.

## 2. Створіть таблиці та політики

У Supabase відкрийте **SQL Editor**, вставте й виконайте `supabase/schema.sql`. Він створює таблиці каталогу, налаштувань, замовлень, RLS-політики й безпечну перевірку доступу адміністратора.

## 3. Створіть обліковий запис адміністратора

У **Authentication → Users** додайте користувача з email і паролем. Скопіюйте його UUID і виконайте в SQL Editor, підставивши UUID:

```sql
insert into public.admin_users (user_id) values ('UUID-КОРИСТУВАЧА');
```

Тільки користувачі, внесені в `admin_users`, можуть переглядати замовлення й змінювати контент. Не вмикайте публічну реєстрацію, якщо вона не потрібна.

## 4. Імпортуйте меню та використовуйте панель

Зайдіть на `admin.html`, увійдіть створеним користувачем і відкрийте вкладку **Меню та ціни**. Натисніть **Завантажити початкове меню** один раз. Далі можна змінювати назви, описи, ціни, вагу, шлях/URL фото та доступність. У вкладці **Тексти й посилання** редагуються контакти, адреса, графік, Instagram та тексти головної сторінки.

Замовлення записуються в Supabase, і їхній статус можна змінювати у вкладці **Замовлення**. Для live-сайту потрібні налаштовані URL і anon key, створені таблиці та опублікований сайт. Зміни меню/текстів будуть видимі після оновлення сторінки.

## Безпека та обмеження

- Anon/publishable key призначений для браузера; RLS-політики в `supabase/schema.sql` обмежують записи за ролями.
- Ніколи не додавайте `service_role` key у файли сайту або репозиторій.
- За замовчуванням нові замовлення надходять зі статусом «Нове». Відвідувачі можуть створювати замовлення, але не читати їх.
- Обмеження частоти замовлень і CAPTCHA не налаштовані; для публічного сайту з трафіком додайте захист від спаму на серверному рівні.
